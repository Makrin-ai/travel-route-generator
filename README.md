# Travel Generator — Генератор маршрутов

## Описание проекта

Веб-приложение для подбора направлений путешествий на основе заданных пользователем критериев: бюджет, тип отдыха, уровень опыта и количество дней. Приложение анализирует базу данных городов и возвращает список подходящих вариантов с детальной информацией о достопримечательностях, активностях, экскурсиях, магазинах и ресторанах.

## Технологический стек

| Компонент | Технология |
|-----------|-------------|
| Серверная логика | Python 3 |
| Веб-фреймворк | Flask |
| Клиентская часть | HTML5, CSS3 |
| Хранение данных | JSON |
| Система контроля версий | Git / GitHub |

## Запуск проекта

### Требования

- Python 3.8 или выше
- Установленный пакетный менеджер pip

### Инструкция по установке и запуску

1. Клонировать репозиторий:

```bash
git clone https://github.com/[ваш_аккаунт]/travel-assistant.git
cd travel-assistant
```
2. Создать виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate  # для macOS/Linux
```

3. Установить зависимости:
```bash
pip install flask
```

4. Запустить приложение:
```bash
python3 src/travel_app/app.py
